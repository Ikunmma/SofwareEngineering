# 箭头小游戏

## 一.游戏简介

这是一款使用 Python 和 Pygame 独立开发的箭头消除小游戏。玩家需要观察箭头的朝向和前方路径，按照合适的顺序点击箭头，让全部箭头飞出棋盘。

游戏包含基础模式与进阶模式，各有 5 个固定关卡。除基础玩法外，当前版本还提供关卡解锁、得分计时、星级评价、下一步提示、随机挑战、AI 自动求解、自动存档、动画和音效等功能。

## 三.安装和运行方法

### 1.Windows：直接运行打包版

打开项目的 [Releases 页面](https://github.com/Ikunmma/SofwareEngineering/releases)，在游戏版本的 **Assets** 中下载 Windows ZIP 压缩包。解压后双击 `ArrowEscape.exe` 即可游玩，无需安装 Python。

Windows 可能对未签名程序显示安全提醒，请确认下载来源后再决定是否运行。

### 2.Python：从源码运行

先安装 Python 3.10 或更高版本。在仓库根目录打开终端，依次运行：

```bash
cd work/arrow-escape
py -m pip install -r requirements.txt
py main.py
```

如果系统使用 `python` 命令，请将 `py` 换成 `python`。

## 四.自行打包 Windows 程序

仅在需要自己生成 EXE 时执行。进入 `work/arrow-escape` 目录后，双击 `build_exe.bat`；也可以在该目录的终端中运行：

```bash
py -m pip install -r requirements.txt -r requirements-build.txt
py -m PyInstaller --noconfirm --clean ArrowEscape.spec
```

生成的程序位于 `dist/ArrowEscape.exe`，已内置图片和中文字体。

## 五.游戏操作说明

### 1.基本规则

- 使用鼠标左键点击棋盘中的箭头。
- 基础模式包含上、下、左、右四种单格箭头。程序会检查箭头与棋盘边界之间的同一行或同一列。
- 进阶模式使用多格彩色折线箭头，点击折线的任意位置均可选中整条箭头，程序会检查箭头头部前进方向上的路径。
- 前方没有其他箭头阻挡时，箭头播放飞出动画并从棋盘消失。
- 前方存在阻挡时，箭头不会消失，并会变红、晃动和触发碰撞提示，同时扣除 1 条生命。
- 每关初始有 3 条生命。生命耗尽时挑战失败，清空所有箭头时挑战成功。

### 2.页面与关卡流程

首页提供“开始游戏”和“玩法说明”按钮。点击开始游戏后进入冒险地图，可以选择基础模式或进阶模式，再选择已经解锁的关卡。

两种模式各有 5 个原创关卡，棋盘会随关卡逐步增大。每种模式默认解锁第 1 关，通关后依次解锁下一关；已完成的关卡会显示绿色勾和历史最佳星级。基础模式和进阶模式的进度分别记录。

游戏页顶部显示当前关卡、生命、剩余箭头、时间和分数，并提供以下操作：

- **重开：** 恢复本关初始棋盘、生命、提示次数、时间和本关分数；
- **静音：** 开启或关闭游戏音效；
- **选关：** 返回当前模式的冒险地图；
- **提示：** 标出下一支可以安全飞出的箭头；
- **AI 求解：** 自动寻找并演示当前局面的完整消除顺序。

通关后可以进入下一关或返回选关；失败后可以重新挑战或返回选关；完成当前模式全部关卡后会显示全部通关页面。

### 3.得分、计时与星级

每关从 0 分开始。成功消除一支箭头增加 100 分，发生碰撞扣除 100 分，分数最低为 0。通关时程序会根据完成时间和剩余生命计算奖励，并给出 1～3 星评价：

- 三星：没有失误，并在本关标准时间内完成；
- 二星：至少保留 1 条生命，并在标准时间的 1.5 倍内完成；
- 一星：成功完成关卡，但未达到二星条件。

本关得分会加入累计分数，重复通关只会保留更高的星级记录。

### 4.提示功能

每关有 3 次提示机会。基础模式会用黄色光圈标出一支可消除箭头，进阶模式会高亮整条可消除折线。每次使用提示会消耗 1 次提示机会和 1 条生命，因此生命只剩 1 条时使用提示会直接进入失败页面。

### 5.随机挑战

冒险地图右下角提供“随机挑战”入口。基础模式会生成随机满格箭阵，进阶模式会生成高密度折线迷阵。每个随机关卡都有独立种子，生成后必须先通过程序求解器验证，确认可以通关后才会进入游戏。随机挑战不受固定关卡的解锁限制，得分计入累计分数，但不会覆盖固定关卡的最佳星级。

### 6.AI 自动求解

点击“AI 求解”后，程序会分析当前剩余棋盘，并逐支播放正确的消除过程。玩家可以先手动消除一部分箭头，再让 AI 求解残局。

求解过程中按钮会变为“暂停”。暂停后，正在播放的箭头会先完成飞出，随后玩家可以手动点击、使用提示、重开或返回选关；再次继续求解时，AI 会根据已经改变的棋盘重新规划。如果当前局面无解，程序会显示提示而不会卡死。

### 7.动画与音效

箭头成功飞出时会显示平滑加速移动、方向色残影和彩色粒子；碰撞时会显示变红、晃动和棋盘红色脉冲。飞出、碰撞、消除、提示和通关均有程序实时合成的短音效。静音选择会自动保存；如果电脑没有可用音频设备，游戏会自动静音且不影响运行。

## 七.游戏进度

程序会自动保存累计分数、两种模式的解锁进度、最佳星级、上次选择的模式与关卡以及静音设置。源码版存档位于项目目录的 `save_data.json`，EXE 版存档位于 `%LOCALAPPDATA%\ArrowEscape\save_data.json`。

冒险地图右上角提供“清除进度”按钮，经过二次确认后才会删除存档并恢复初始状态。存档文件缺失、损坏或包含无效数据时，程序会安全地使用默认进度启动。

## 八.测试方法

运行以下命令执行自动化测试：

```bash
py -m unittest discover -s tests -v
```

测试覆盖四方向与边界判定、固定关卡可解性、进阶折线路径、提示和生命、得分与星级、进度保存与清除、随机挑战、AI 暂停与重新规划、动画、音效静音以及完整页面流程。自动化测试不能代替开发者本人对全部关卡的实际试玩。

## 九.素材与许可

项目使用 Pygame 绘制界面、棋盘和动画。按钮、方向箭头、星星及英文字体选自 [Kenney UI Pack](https://kenney.nl/assets/ui-pack)，采用 CC0 1.0 许可；中文字体采用 SIL OFL 1.1 授权的 [Noto Sans SC](https://github.com/notofonts/noto-cjk)。完整许可见 `assets/LICENSES.md`。

核心玩法参考了[微信小游戏《一箭又一箭》](https://sj.qq.com/appdetail/wx69949b45b793b612)。本项目只借鉴“点击无阻挡箭头使其飞出”的基础规则，程序代码、关卡和界面均独立完成，未使用原商业游戏的代码、图片或音效。
