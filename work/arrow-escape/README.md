# 一箭又一箭

一个使用 Python 和 Pygame 独立开发的网格箭头消除小游戏。玩家需要观察每支箭头前方的路径，按正确顺序让全部箭头飞出棋盘。

## 开发环境

- Python 3.10 或更高版本
- Pygame 2.6.1

## 安装和运行

在 `work/arrow-escape` 目录打开终端，先安装依赖：

```bash
py -m pip install -r requirements.txt
```

然后启动游戏：

```bash
py main.py
```

如果电脑使用 `python` 命令，也可以把上面两条命令中的 `py` 换成 `python`。

## 游戏操作

- 在主页选择“基础模式”或“进阶模式”；
- 使用鼠标左键点击棋盘中的箭头；
- 箭头前方没有其他箭头时，它会飞出棋盘并消失；
- 箭头被阻挡时会变红晃动，并消耗一次失误机会；
- 清空本关全部箭头即可进入下一关；
- 三次失误耗尽后，可以重新挑战当前关卡；
- 游戏中可随时点击“重新开始”恢复本关。

### 两种游戏模式

- **基础模式：** 使用单格箭头，按照作业要求检查同一行或同一列。三个关卡依次采用 5×5、6×6、7×7 满格箭阵，分别包含 25、36、49 支箭头。随机选择消除顺序和可行方向，让箭头方向交错分布。
- **进阶模式：** 使用由多个相邻格子组成的彩色折线箭头。点击折线任意位置即可选择整条箭头，并检查箭头端点到边界之间是否存在其他路线。三个关卡依次采用 16 行×12 列、18 行×14 列、20 行×16 列网格。路线随机生长，混合短线、长线和多次转弯，网格覆盖率约为 91%、91%、87%。
- **下一步提示：** 点击游戏页左下角的“提示”，界面会给出坐标说明，并用黄色光圈标出一个当前可以安全消除的箭头。

### 随机关卡与可解性

两种模式使用固定随机种子，因此重新开始会恢复同一布局，不会每次打开都换题。
进阶模式每次加入一条头部出口畅通的路线，再向后随机延长身体；后来加入的路线可能挡住先加入的路线，按加入顺序倒序消除就能通关。生成器尝试有限张候选棋盘，选取覆盖率最高的一张；路线不重叠，留少量空格避免强行填充造成规律排列。

## 界面与素材

项目使用 Pygame 绘制渐变背景、卡片、棋盘、状态栏和动画；按钮、方向箭头、星星及英文字体选自 [Kenney UI Pack](https://kenney.nl/assets/ui-pack)，采用 CC0 1.0 许可。完整许可说明见 `assets/LICENSES.md`。

核心玩法参考了[微信小游戏《一箭又一箭》应用宝页面](https://sj.qq.com/appdetail/wx69949b45b793b612)。本项目仅借鉴“点击无阻挡箭头使其飞出”的基础规则和深色点阵棋盘氛围；代码、单格箭头关卡和界面排版均独立完成，也未使用原游戏的商业美术素材。
