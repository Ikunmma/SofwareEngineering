# 一箭又一箭

一个使用 Python 和 Pygame 独立开发的网格箭头消除小游戏。玩家需要观察每支箭头前方的路径，按正确顺序让全部箭头飞出棋盘。

## 开发环境

- Python 3.10 或更高版本
- Pygame 2.6.1

## 安装和运行

在 `work/arrow-escape` 目录打开终端，先安装依赖：

```bash
py -m pip install -r requirements.txt
```

然后启动游戏：

```bash
py main.py
```

如果电脑使用 `python` 命令，也可以把上面两条命令中的 `py` 换成 `python`。

## 游戏操作

- 主页点击“开始游戏”，进入冒险地图；
- 在地图页选择“基础模式”或“进阶模式”，再点击关卡节点；
- 使用鼠标左键点击棋盘中的箭头；
- 箭头前方没有其他箭头时，它会飞出棋盘并消失；
- 箭头被阻挡时会变红晃动，并消耗一次失误机会；
- 清空本关全部箭头即可进入下一关；
- 三次失误耗尽后，可以重新挑战当前关卡；
- 游戏中可随时点击“重新开始”恢复本关。
- 游戏中点击右上角“选关”可返回当前模式的冒险地图；通关、失败和全部通关页面也提供“返回选关”按钮。

### 两种游戏模式

- **基础模式：** 使用单格箭头，按照作业要求检查同一行或同一列。五个关卡从 5×5 逐步增加到 9×9，分别包含 25、36、49、64、81 支箭头。随机选择消除顺序和可行方向，让箭头方向交错分布。
- **进阶模式：** 使用由多个相邻格子组成的彩色折线箭头。点击折线任意位置即可选择整条箭头，检查头部到边界的射线是否被身体或其他路线挡住。通路畅通时，头部向前，身体沿原折线依次滑出。五个关卡从 16 行×12 列逐步增加到 24 行×20 列。路线随机生长并通过延长尾部、插入弯路补密。
- **下一步提示：** 点击游戏页左下角的“提示”，界面给出坐标说明。基础模式圈出箭头，进阶模式高亮整条可消除路线及其箭头端点。
- **关卡选择：** 主页点击“开始游戏”进入冒险地图，切换基础或进阶模式后，可以从五个路线节点中直接开始任意一关。
- **通关标记：** 已完成的关卡节点会显示绿色勾和本次运行中获得的最好星级；基础模式与进阶模式分别记录，重复挑战不会覆盖更高星级。

### 得分、计时与星级

每关从 0 分开始，成功消除一支箭头增加 100 分，发生碰撞扣除 100 分且最低为 0 分。游戏页顶部实时显示本关用时和分数。通关时会根据标准时间计算限时奖励，并按剩余失误机会增加奖励；本关分数会加入连续挑战的累计分数。

- 三星：没有失误，并在本关标准时间内完成；
- 二星：至少保留一次失误机会，并在标准时间的 1.5 倍内完成；
- 一星：完成关卡，但未达到二星条件。

重新开始或失败后重新挑战会重置本关时间、分数和星级，进入下一关时累计分数会保留。从地图直接开始新的挑战时，累计分数从 0 开始。

### 随机关卡与可解性

两种模式使用固定随机种子，因此重新开始会恢复同一布局，不会每次打开都换题。
进阶模式每次加入一条头部出口畅通的路线，再向后随机延长身体，身体不能进入自身出口射线。后来加入的路线可能挡住先加入的路线，按加入顺序倒序消除就能通关。补密时禁止新增身体进入自身及后来路线的出口射线，保留这一通关顺序。生成器尝试有限张候选棋盘，选取覆盖率最高的一张。

运行 `py -m unittest discover -s tests -v` 可执行自动化测试。测试包含自挡出口、密度、逆序可解性，以及通过鼠标事件逐次点击提示和箭头、按帧播放动画、进入下一关直至全部通关的界面流程。自动化回放不代替提交者本人试玩。

## 界面与素材

项目使用 Pygame 绘制渐变背景、卡片、棋盘、状态栏和动画；按钮、方向箭头、星星及英文字体选自 [Kenney UI Pack](https://kenney.nl/assets/ui-pack)，采用 CC0 1.0 许可。完整许可说明见 `assets/LICENSES.md`。

核心玩法参考了[微信小游戏《一箭又一箭》应用宝页面](https://sj.qq.com/appdetail/wx69949b45b793b612)。本项目仅借鉴“点击无阻挡箭头使其飞出”的基础规则和深色点阵棋盘氛围；代码、单格箭头关卡和界面排版均独立完成，也未使用原游戏的商业美术素材。
